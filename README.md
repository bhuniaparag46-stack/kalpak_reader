# কল্পক রিডার

বাংলা পড়ার জন্য অ্যান্ড্রয়েড নথি-পাঠক। DOCX, ODT, EPUB ও TXT ফাইল খোলে; হরফ, মাপ, পঙ্‌ক্তির ব্যবধান ও পটভূমি বদলানো যায়; পৃষ্ঠাচিহ্ন রাখে, শেষ পড়া জায়গা মনে রাখে, আর ফোনের বাংলা কণ্ঠে লেখা পড়ে শোনায়। অ্যাপ চালাতে ইন্টারনেট লাগে না।

## ফোনে বসানো

এই পাতার **Releases** অংশ থেকে সবচেয়ে নতুন `KalpakReader-*.apk` ফাইলটি নামিয়ে খুলুন। প্রথমবার ফোন "অজানা উৎস থেকে অ্যাপ বসানোর" অনুমতি চাইবে। অ্যান্ড্রয়েড ৮ বা তার পরের সংস্করণ লাগবে।

## কীভাবে তৈরি হয়

`main` শাখায় কিছু বদলালেই GitHub Actions নিজে থেকে APK বানিয়ে Releases-এ রাখে (`.github/workflows/build.yml`)।

- `app/src/main/assets/` — অ্যাপের পর্দা ও নথি পড়ার কোড (HTML, CSS, JavaScript)
- `app/src/main/java/` — অ্যান্ড্রয়েড খোলস: ফাইল বাছাই, সঞ্চয়, পাঠের কণ্ঠ

## হরফ ও লাইসেন্স

Noto Serif Bengali, Noto Sans Bengali, Tiro Bangla ও Hind Siliguri হরফ SIL Open Font License 1.1-এর অধীনে ব্যবহৃত; লাইসেন্সের লেখা APK-র `assets/fonts/` ফোল্ডারে থাকে।

## সই করার চাবি সম্পর্কে

`app/kalpak.keystore` চাবিটি এই প্রকাশ্য রিপোজিটরিতেই রাখা, যাতে প্রতিটি সংস্করণ আগেরটির ওপর বসানো যায়। তাই এই চাবি অ্যাপের উৎস প্রমাণ করে না; APK শুধু এই রিপোজিটরির Releases থেকেই নামান।
